These related issues describe observable *symptoms* of a session going away (renderer crash on a stale lastProjectSession pointer, unhandled rejection bursts from stale subagent sessions, survivor references). This issue is narrower and distinct: it targets the two detection predicates (`isSessionNotFoundError` / `isLocalSessionNotFoundError`) that decide whether an incoming error is a not-found shape at all. Fixing the predicates makes all three symptom paths route correctly through the existing "session gone" handling instead of treating the error as generic.

Cross-reference: the mQorva fork has a related fix for the survivor-reference path (#47683 / stale-session-references); this issue covers the shared predicate that both that fix and the crash/overlay paths depend on.
